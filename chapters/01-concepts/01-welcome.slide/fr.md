# Bienvenue sur TakumiDo

> Une plateforme ouverte de formation pour des sessions d'apprentissage live et synchronisées.

::: slot left

**TakumiDo** est une plateforme web qui permet aux formateurs de dispenser des cours interactifs à leurs apprentis en temps réel.

Les slides sont synchronisées en direct entre le formateur et tous les apprentis connectés. Chaque apprenti peut naviguer librement dans les slides déjà présentées tout en gardant la visibilité sur la position actuelle du formateur.

Les cours sont rédigés sous forme de dépôts structurés combinant des manifestes YAML, du contenu Markdown et un système de layouts déclaratif — aucun code frontend n'est requis.
