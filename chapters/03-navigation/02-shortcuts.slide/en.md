# Keyboard Shortcuts

> Control your session without taking your eyes off the content.

::: slot body

TakumiDô provides dedicated keyboard shortcuts for both roles, enabling navigation without ever leaving the full-screen view.

### Apprentice shortcuts

| Key | Action |
|-----|--------|
| `Space` or `P` | Toggle Play ↔ Pause (resync if in Pause) |
| `←` | Previous slide (triggers Pause if in Play) |
| `→` | Next slide (only if unlocked) |

### Trainer shortcuts

| Key | Action |
|-----|--------|
| `←` | Previous slide |
| `→` | Next slide |
| `F` | Open / close the projection window |

### Notes

- In **Play** mode, `←` automatically triggers **Pause** and moves back one slide — the apprentice leaves sync to review a previous slide.
- In **Pause** mode, `Space` / `P` re-enables sync and brings the apprentice back to the trainer's current position (**resync**).
- Trainer and apprentice shortcuts are independent: each role has its own view and controls.

:::
